# 🐧 무펭이즘 후원

무펭이즘을 지지해주셔서 감사합니다.

## 후원 방법

무펭이즘은 현재 별도의 결제 수단이나 크립토 연동 없이 운영됩니다.
프로젝트를 지원하고 싶다면 다음 방법으로 참여해 주세요.

- ⭐ GitHub 저장소에 Star
- 🐛 이슈 제보 및 개선 제안 (GitHub Issues)
- 🔧 Pull Request로 코드/문서 기여
- 📣 커뮤니티에 무펭이즘 공유

## 아카이브 노트

초기 프로토타입 문서에는 온체인 토큰/후원 주소 개념이 포함되어 있었으나,
현재 포지셔닝에서는 어떤 크립토 자산이나 토큰 기능도 제공하지 않습니다.
이 파일은 히스토리 보존을 위해 중립적인 내용으로 대체되었습니다.

---

> 기여와 피드백이 무펭이즘을 성장시키는 가장 큰 에너지입니다.
