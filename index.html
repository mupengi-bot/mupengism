Mupengism

A workspace template for AI agents that remember yesterday.

Mupengism is an OpenClaw-oriented workspace template and skill package. It provides conventions for continuity, file-based memory, self-identity documents, and behavior rules — so an agent can pick up where it left off.

What it is

  • A workspace template & skill package you layer on top of OpenClaw (or a similar environment)
  • File-based memory (memory/), self-identity (SOUL.md), behavior rules (AGENTS.md)
  • Small local CLI helpers: init, doctor, grow, reflect

What it is not

  • Not a runtime or platform — gateway, channels, scheduling, and hosting come from OpenClaw or your own environment
  • Not a hosted or paid service
  • No cryptocurrency or coins — there is nothing to buy

Quick start

npx mupengism init
vim SOUL.md
