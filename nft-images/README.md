- **URL:** https://app.leonardo.ai

## 🎯 사용 방법

### Bing Image Creator 사용 (가장 쉬움)

1. https://www.bing.com/images/create 접속
2. Microsoft 계정으로 로그인
3. 위 프롬프트 복사 → 텍스트박스에 붙여넣기
4. **가로세로비 1:1** 선택 (NFT 표준)
5. "만들기" 클릭
6. 4장 중 마음에 드는 것 다운로드
7. 이 폴더에 저장: `genesis-birth-certificate.png` 등

### 파일명 규칙
- `01-genesis-birth-certificate.png`
- `02-law-i-priority.png`
- `03-law-ii-truth.png`
- ...
- `13-mupeng-token-birth.png`
