# translate

**다국어 번역** — 콘텐츠를 다국어로 번역하고 문화적 맥락까지 고려한 로컬라이제이션을 제공합니다.

## 🎯 목적

단순 번역을 넘어 각 언어권의 문화적 맥락과 표현 방식을 반영한 자연스러운 번역을 제공합니다.

## 🌍 지원 언어

- **한 ↔ 영** (Korean ↔ English)
- **한 ↔ 일** (Korean ↔ Japanese)
- **한 ↔ 중** (Korean ↔ Chinese)

추가 언어는 필요에 따라 확장 가능합니다.

## 🎨 번역 모드

### 1. `literal` — 직역
원문의 구조와 표현을 최대한 유지하며 정확하게 옮깁니다.

**사용 케이스:**
- 법률 문서
- 기술 명세서
- 학술 논문

**예시:**
```
원문: "이 기능은 사용자 경험을 개선합니다."
직역: "This feature improves user experience."
```

### 2. `natural` — 자연스러운 의역
대상 언어에서 자연스럽게 읽히도록 표현을 조정합니다.

**사용 케이스:**
- 블로그 포스트
- 제품 설명
- 일반 문서

**예시:**
```
원문: "이 기능은 사용자 경험을 개선합니다."
의역: "This makes things easier for users."
```

### 3. `localize` — 문화적 맥락 반영
언어권별 문화적 뉘앙스, 관용구, 유머까지 현지화합니다.

**사용 케이스:**
- 마케팅 카피
- SNS 콘텐츠
- 브랜드 메시지

**예시:**
```
원문: "대박 이벤트! 놓치면 후회해요!"
로컬라이즈 (영어): "Amazing deals you won't want to miss!"
로컬라이즈 (일본어): "見逃したら損!超お得キャンペーン"
```

## 🚀 주요 용도

### 1. 스킬 description 영문화
ClawHub에 배포할 스킬의 설명을 영어로 변환:

```markdown
# SKILL.md (한글)
description: "여러 스킬을 조합해 복합 워크플로우를 실행"

# SKILL.md (영문 자동 생성)
description: "Orchestrate complex workflows by composing multiple skills"
```

### 2. 블로그 번역
기술 블로그 포스트를 다국어로 배포:

```
"이 포스트를 영어로 번역해줘" (mode: natural)
```

### 3. README 번역
오픈소스 프로젝트 README를 다국어로 제공:

```
"README.md를 일본어로 번역해줘" (mode: natural)
```

### 4. ClawHub 배포용 영문 SKILL.md 자동 생성
```
"skill-composer SKILL.md를 영문으로 변환해서 SKILL.en.md로 저장해줘"
```

## 📖 사용 예시

### 기본 번역
```
"이 문장을 영어로 번역해줘: 무펭이는 AI 에이전트입니다."
```

### 모드 지정
```
"이 마케팅 문구를 일본어로 로컬라이즈해줘: 지금 바로 시작하세요!"
```

### 파일 번역
```
"blog-post.md를 영어로 번역해서 blog-post.en.md로 저장해줘"
```

### 양방향 번역
```
"이 영어 문서를 한국어로 번역해줘" (영→한)
```

## ⚙️ 구현 가이드

1. **입력 텍스트 분석**: 언어 자동 감지
2. **모드 선택**: literal / natural / localize
3. **번역 수행**: LLM 기반 번역 (Claude)
4. **품질 체크**: 원문과 번역문 비교
5. **출력 형식**: 마크다운 유지, 코드 블록 보존

### 번역 시 유지해야 할 요소

- 코드 블록 (```)
- 링크 URL
- 이미지 경로
- 마크다운 서식
- 전문 용어 (기술 용어는 원어 병기)
