# Skill Chain Templates

자주 사용하는 스킬 조합 파이프라인 모음. 복합 요청을 효율적으로 처리하기 위한 템플릿.

---

## 1. 콘텐츠 풀 파이프라인

**이름**: content-full-pipeline  
**트리거**: "콘텐츠 만들어줘", "포스팅해줘", "인스타 올릴거 만들어"

**설명**: 아이디어부터 인스타그램 게시까지 전체 콘텐츠 제작 파이프라인

**스텝**:
1. **seo-content-planner** — 키워드 리서치 + 콘텐츠 주제 선정
2. **copywriting** — SEO 최적화된 텍스트 작성
3. **cardnews** — 카드뉴스 이미지 생성 (1:1 정사각형)
4. **insta-post** — 인스타그램 업로드 (형님 승인 필수)

**출력**: 인스타그램 게시물 URL + 성과 추적 시작

## 2. 경쟁사 분석 보고서

**출력**: 보고서 MD 파일 + 이메일 발송 확인

## 4. 주간 종합 리뷰

**이름**: weekly-review  
**트리거**: "주간 리뷰", "이번 주 정리해줘", "한 주 요약"

**설명**: 성과, 비용, 반성을 종합한 주간 보고서

**스텝** (병렬 실행):
1. **self-eval** — 지난 주 실수/개선점 분석
2. **tokenmeter** — 주간 토큰 사용량 + 비용 집계
3. **performance-tracker** — 콘텐츠 성과 분석 (좋아요/댓글/조회수)

**스텝** (순차 실행):
4. **daily-report** — 위 3가지 결과를 통합한 주간 보고서 생성

**출력**: weekly-review-YYYY-MM-DD.md

## 8. 안전한 릴리즈

**이름**: safe-release  
**트리거**: "릴리즈", "배포해줘", "프로덕션 올려"

**설명**: 코드 리뷰 → Git 커밋 → 배포 체크리스트 확인

**스텝**:
1. **code-review** — 코드 변경사항 검토 + 위험도 평가
2. **git-auto** — 커밋 + 푸시 (code-review 통과 시에만)
3. **release-discipline** — 배포 전 체크리스트 확인 (DB 마이그레이션, 환경변수 등)

**안전 장치**:
- code-review에서 심각도 HIGH 감지 시 → 커밋 차단 + notification-hub
- 형님 최종 승인 필수

**출력**: Git 커밋 해시 + 배포 체크리스트 완료 확인

**출력**: 즉시 알림 + 로그 기록

## 체인 실행 규칙

### 병렬 vs 순차
- **병렬 실행**: 서로 의존성 없는 스킬들 (sessions_spawn 사용)
- **순차 실행**: 이전 스킬 결과를 다음 스킬이 필요로 하는 경우

### 데이터 전달
- 스킬 간 데이터는 `events/` 폴더에 JSON 이벤트로 저장
- 각 스킬은 `events/latest-{skill-name}.json` 형식으로 결과 저장
- 다음 스킬은 해당 파일을 읽어서 입력으로 사용

### 에러 처리
- 체인 중간에 스킬 실패 시 → 부분 결과 저장 + notification-hub 알림
- 형님 승인 대기 중 타임아웃(1시간) → 자동 취소 + 알림
- 같은 체인 3회 반복 실행 감지 → 무한 루프 방지 중단
