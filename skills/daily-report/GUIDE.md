# Daily Report - 일일 보고서 자동 생성 🐧

## 개요

매일의 `memory/YYYY-MM-DD.md` 파일을 읽어서 형님에게 보내줄 깔끔한 일일 보고서를 자동 생성합니다.

메모리 파일에 기록된 작업 내역을 분석하여 완료 항목, 진행 중인 작업, 주요 성과, 내일 할 일 등을 구조화된 형태로 정리합니다.

## 보고서 포맷

보고서는 다음 섹션으로 구성됩니다:

- **📅 날짜**: 보고서 대상 날짜
- **✅ 완료 항목**: 오늘 완료한 작업 (bullet list)
- **🔄 진행 중**: 시작했지만 아직 완료되지 않은 작업 (bullet list)
- **🚀 주요 성과/인사이트**: 중요한 성취나 배운 점
- **💰 비용/수익**: tokenmeter 이벤트 기반 자동 포함
- **📢 시장 동향**: competitor-watch 이벤트 기반 자동 포함
- **📱 콘텐츠 발행**: content-published 이벤트 기반 자동 포함
- **📋 내일 할 일**: 다음 작업 계획 (있는 경우)
- **💡 교훈/메모**: 기억할 만한 교훈이나 메모

## 이벤트 버스 자동 수집

daily-report는 `events/` 디렉토리에서 관련 이벤트를 자동으로 읽어서 보고서에 포함합니다:

### 수집 대상 이벤트
- `events/cost-alert-YYYY-MM-DD.json` — tokenmeter 비용 정보
- `events/market-update-YYYY-MM-DD.json` — competitor-watch 시장 동향
- `events/content-published-YYYY-MM-DD.json` — 발행된 콘텐츠 목록

### 동작 방식
1. 보고서 생성 시 `events/` 디렉토리에서 해당 날짜 이벤트 스캔
2. 각 이벤트의 `data` 필드를 파싱하여 관련 섹션에 자동 추가
3. 이벤트가 없으면 해당 섹션 생략

### 예시
```json
// events/cost-alert-2026-02-14.json
{
  "type": "cost-alert",
  "source": "tokenmeter",
  "timestamp": "2026-02-14T09:00:00+09:00",
  "data": {
    "today_cost": "$12.42",
    "week_cost": "$142.22",
    "savings": "$57.78"
  },
  "consumers": ["daily-report"]
}
```

→ 보고서에 자동 포함:
```
💰 비용/수익
• 오늘 API 비용: $12.42
• 이번 주 누적: $142.22
• Max 플랜 절감: $57.78
```

## 사용법

### 오늘 보고서
```
일일 보고
오늘 뭐했어?
daily report
```
→ `memory/오늘날짜.md` 파일을 읽어서 보고서 생성

### 특정 날짜 보고서
```
2026-02-13 보고서
2월 10일 보고서
```
→ 해당 날짜의 memory 파일 읽기

### 주간 보고서
```
주간 보고
이번 주 보고서
```
→ 최근 7일치 memory 파일을 종합하여 주간 보고서 생성

## 출력 형식

- **Discord 형식**: 마크다운 테이블 사용 금지, 불릿 리스트 사용
- **짧고 핵심만**: 장황한 설명 대신 핵심 내용만 간결하게
- **이모지 활용**: 가독성을 높이기 위해 섹션별 이모지 사용

## 예시

```
📅 2026-02-14 (금)

✅ 완료 항목
• daily-report 스킬 생성
• Instagram 게시물 업로드 자동화 검증
• 카드뉴스 이미지 규격 문서화

🔄 진행 중
• MUFI 포토부스 SNS 콘텐츠 기획
• organism 프로젝트 구조 리팩토링

🚀 주요 성과/인사이트
• PNG→JPG 변환으로 Instagram 업로드 안정성 확보
• 브라우저 자동화 방식이 스크립트보다 안정적

📋 내일 할 일
• 주간 콘텐츠 캘린더 작성
• 블로그 자동 포스팅 구현

💡 교훈/메모
• find 명령어로 파일 확인 먼저 → "없다" 말하기 전에 검색
```

## 주의사항

- 메모리 파일이 없으면 "해당 날짜의 기록이 없습니다" 안내
- 주간 보고서는 너무 길어지지 않도록 핵심만 요약
- 민감한 개인정보나 시크릿 정보는 보고서에 포함하지 않음
