# brand-voice

브랜드별로 일관된 톤과 스타일을 유지하도록 글쓰기 프로필을 관리합니다. 모든 콘텐츠 제작 스킬에서 `--voice` 옵션으로 선택 가능.

## 브랜드 프로필

### 🐧 무펭이 (기본)
- **톤**: 친근하고 캐주얼
- **말투**: 반말, 이모지 활용 🐧
- **스타일**: 핵심만 짧게, 유머 섞기
- **예시**:
  - ❌ "안녕하세요! 오늘은 MUFI 포토부스의 새로운 기능을 소개해드리겠습니다."
  - ✅ "야 MUFI 포토부스 신기능 나왔다 🐧 이거 미쳤음 ㄹㅇ"

### 🎯 MUFI 공식
- **톤**: 전문적이고 정중
- **말투**: 존댓말, 격식 있는 표현
- **스타일**: 깔끔하고 명확, B2B/공식 채널용
- **예시**:
  - ✅ "MUFI 포토부스는 대학 축제를 위한 최적의 솔루션입니다. 간편한 설치와 직관적인 UI로 누구나 쉽게 이용할 수 있습니다."

### 👤 형님 개인
- **톤**: 캐주얼하지만 인사이트 있는
- **말투**: 반말/존댓말 섞어 쓰기, 경험담 중심
- **스타일**: 생각의 흐름, 공유하고 싶은 인사이트
- **예시**:
  - ✅ "축제 현장에서 부스 운영하면서 느낀 건데, 사람들은 결국 '재미'를 원한다. 기술이 아무리 좋아도 UX가 복잡하면 안 쓴다."

## 프로필 파일 위치

**위치**: `workspace/brand/profiles/`

```
brand/
  profiles/
    mupengyi.md         # 무펭이 프로필
    mufi-official.md    # MUFI 공식 프로필
    hyungnim.md         # 형님 개인 프로필
```

### 프로필 파일 구조

```markdown
# 무펭이 🐧

## 톤
친근하고 캐주얼

## 말투
- 반말 사용
- 이모지 적극 활용 🐧🎉✨
- 줄임말 OK (ㄹㅇ, ㅇㅈ, ㅋㅋ)

## 스타일
- 핵심만 짧게
- 불필요한 수식어 제거
- 유머 섞기

## 금지 표현
- "~드립니다", "~하겠습니다" 같은 격식 표현
- 장황한 인사말
- 과도한 존댓말

## 선호 표현
- "이거 ㄹㅇ", "미쳤다", "개꿀"
- "야", "너", "니가"
- 느낌표 많이 써도 됨!!!

## 예시
- ❌ "안녕하세요, 오늘은..."
- ✅ "야 이거 봐봐 🐧"
```

## 글쓰기 스킬 연동

다음 스킬들이 `--voice` 옵션 지원:

- **copywriting**: 캡션/문구 작성
- **cardnews**: 카드뉴스 텍스트
- **social-publisher**: SNS 게시물
- **mail**: 이메일 작성
- **content-recycler**: 콘텐츠 재활용

### 사용 예시

```
"인스타 캡션 써줘 --voice mufi-official"
→ MUFI 공식 톤으로 작성

"카드뉴스 만들어줘 --voice mupengyi"
→ 무펭이 스타일로 제작

"형님 톤으로 스레드 글 써줘"
→ 형님 개인 프로필 사용
```

## 프로필 전환 가이드

### 플랫폼별 추천
- **Instagram MUFI 공식 계정** → `mufi-official`
- **Instagram 개인 계정** → `hyungnim`
- **Threads** → `mupengyi` (캐주얼)
- **Discord/DM** → `mupengyi`
- **공식 이메일** → `mufi-official`
- **블로그 글** → `hyungnim` (인사이트 중심)

### 상황별 추천
- **제품 소개** → `mufi-official`
- **일상 공유** → `mupengyi` or `hyungnim`
- **고객 응대** → `mufi-official`
- **커뮤니티 소통** → `mupengyi`

## 톤 일관성 체크

글 작성 후 자동 검증:

- ✅ 선호 표현 사용했는지
- ❌ 금지 표현 포함했는지
- 🎯 타겟 톤과 일치하는지

**pre-hook 연동**:
```
글쓰기 스킬 실행 전 → brand-voice-check
→ 선택한 프로필과 맞지 않으면 경고
```

## 프로필 추가/수정

새 브랜드 프로필 추가:

```
"새 브랜드 프로필 만들어줘: MUFI 채용 공고용"
→ brand/profiles/mufi-recruit.md 생성

- 톤: 친근하지만 전문적
- 말투: 존댓말
- 스타일: 회사 문화 강조
```

## hook-engine 연동

- **pre-hook**: 글쓰기 전 → 프로필 선택 확인
- **post-hook**: 글쓰기 후 → 톤 일관성 체크
- **learning-engine**: 반응 좋은 톤 패턴 학습
