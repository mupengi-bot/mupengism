# 무펭이 이모지/스티커 세트 기획 🎭

> 메신저, SNS, 디스코드 등에서 사용할 이모지/스티커 10종 컨셉

---

## 기획 방향

### 타겟 플랫폼
- 카카오톡 이모티콘
- 디스코드 서버 이모지
- 슬랙 커스텀 이모지
- SNS 스티커

### 디자인 원칙
1. **32px에서도 인식** - 작은 사이즈 최적화
2. **감정 명확** - 한눈에 뭔지 알 수 있게
3. **다용도** - 다양한 상황에서 활용
4. **무펭이 정체성** - 안테나, 볼터치 등 아이덴티티 유지

## 스티커 10종 컨셉

### 1. 👋 "왔어!" (인사/등장)
| 항목 | 내용 |
|------|------|
| **표정** | 밝은 미소, 눈 반짝 |
| **포즈** | 한쪽 날개 흔들며 인사 |
| **텍스트** | "왔어!" 또는 없음 |
| **용도** | 대화 시작, 등장, 인사 |
| **무드** | 밝고 활기참 |

---

## 제작 가이드

### 사이즈
- **카카오톡**: 360x360px (PNG, 최대 500KB)
- **디스코드**: 128x128px (PNG/GIF)
- **슬랙**: 128x128px (PNG/GIF)

### 파일 포맷
- 정적 스티커: PNG (투명배경)
- 움직이는 스티커: GIF 또는 APNG

### 애니메이션 가이드
| 스티커 | 움직임 |
|------|------|
| 인사 | 날개 좌우로 흔들기 (2회) |
| 완료 | 컨페티 터지는 효과 |
| 생각 | 안테나 깜빡깜빡 |
| 졸림 | zzZ 올라가는 애니메이션 |
| 달려 | 다리 움직이며 뛰기 |
