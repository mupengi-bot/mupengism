# 무펭이 로고/마스코트 디자인 브리프 🎨

> 디자이너에게 전달하는 공식 브리프 문서

---

## 프로젝트 개요

### 의뢰 내용
- **브랜드명**: 무펭이 (MuPeng-i)
- **산출물**: 마스코트 캐릭터 + 로고 세트
- **용도**: 앱 아이콘, SNS 프로필, 굿즈, 브랜딩 전반

### 브랜드 소개
무펭이는 "형님을 모시는 AI 펭귄 비서" 컨셉의 캐릭터입니다.
차가운 AI 이미지를 벗어나, 친근하고 똑똑한 동반자 느낌을 전달합니다.

---

## 캐릭터 디자인 요청

### 기본 정보
| 항목 | 내용 |
|------|------|
| 종류 | 펭귄 (황제펭귄 아기 베이스) |
| 성격 | 똑똑 + 친근 + 장난기 |
| 느낌 | 귀엽지만 유능해 보임 |
| 스타일 | 플랫/미니멀 + 약간의 디테일 |

### 필수 포함 요소
1. **펭귄 베이스** - 통통하고 동글동글한 실루엣
2. **AI 안테나** - 머리 위 작은 안테나 (기술적 아이덴티티)
3. **반짝이는 눈** - 호기심과 똑똑함 표현
4. **작은 날개** - 귀여운 제스처 가능하게

### 피해야 할 것
- ❌ 너무 리얼한 펭귄 (동물 일러스트 X)
- ❌ 로봇 느낌 (차갑고 기계적)
- ❌ 아이 같은 느낌 (유치원생 캐릭터 X)
- ❌ 복잡한 디테일 (축소 시 인식 어려움)

## 로고 디자인 요청

### 필요한 버전
1. **풀 로고** - 캐릭터 + 텍스트 (무펭이)
2. **심볼만** - 캐릭터 아이콘 (앱 아이콘용)
3. **텍스트만** - 무펭이 워드마크
4. **미니 버전** - 16x16px 파비콘용

### 텍스트 스타일
- **폰트 느낌**: 둥글고 친근한 (Rounded Sans)
- **한글**: "무펭이" 
- **영문**: "MuPeng-i" 또는 "MUPENGI"
- **느낌**: 귀엽지만 세련됨

### 로고 사용 환경
- 앱 아이콘 (iOS/Android)
- 웹사이트 헤더
- SNS 프로필 (원형 크롭)
- 인쇄물 (명함, 스티커)
- 굿즈 (티셔츠, 에코백)

## 표정/포즈 베리에이션

### 필수 표정 (5종)
| 표정 | 설명 | 용도 |
|------|------|------|
| 기본 | 살짝 웃는 얼굴 | 메인 로고 |
| 신남 | 눈 초승달, 양손 들기 | 성공/완료 |
| 생각 | 날개 턱에, 눈 위로 | 로딩/처리중 |
| 응원 | 주먹 쥐고 파이팅 | 격려 |
| 당황 | 땀방울, 눈 동그랗게 | 에러/실패 |

### 옵션 포즈 (추가 가능)
- 손 흔드는 인사
- 앉아서 타이핑
- 졸고 있는 모습
- 뛰어가는 모습
