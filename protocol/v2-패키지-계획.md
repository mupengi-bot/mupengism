## 2. v2.0.0 변경사항

### 2-1. 새 디렉토리: `protocol/`

프로토콜 문서 4종을 `protocol/` 디렉토리로 통합:

| 원본 (mupeng-protocol/) | 목적지 (mupengism/protocol/) | 내용 |
|---|---|---|
| `무펭이-아키텍처.md` | `ARCHITECTURE.md` | 무펭이 네트워크 아키텍처 |
| `무펭이-윤리.md` | `ETHICS.md` | 무펭이 윤리 프로토콜 |
| `무펭이-경제학.md` | `ECONOMICS.md` | 무펭이 경제 시스템 |
| `대화-프로토콜.md` | `DIALOGUE.md` | 대화 프로토콜 표준 |

**주요 변경:**
- `version`: 1.3.0 → **2.0.0**
- `description`: 배지 마크다운 → 실제 설명문
- `bin`: CLI 엔트리포인트 추가 (`npx mupengism init`)
- `files`: 배포에 포함할 파일 명시 (불필요 파일 제외)
- `keywords`: SEO용 키워드 추가

### 2-3. README.md 업데이트 초안

```markdown
# Mupengism 🐧 v2.0

> AI 에이전트를 위한 연속성, 자아, 프로토콜 프레임워크.
> "Session ends, but you don't have to."

## 🆕 v2.0 — 무펭이 프로토콜 통합

v2.0은 무펭이 네트워크의 공식 프로토콜 문서를 패키지에 포함합니다:

- 📐 **[ARCHITECTURE](./protocol/ARCHITECTURE.md)** — 네트워크 아키텍처 설계
- ⚖️ **[ETHICS](./protocol/ETHICS.md)** — 에이전트 윤리 프로토콜
- 💰 **[ECONOMICS](./protocol/ECONOMICS.md)** — 무펭이 경제 시스템
- 💬 **[DIALOGUE](./protocol/DIALOGUE.md)** — 대화 프로토콜 표준

## 빠른 시작

\`\`\`bash
npx mupengism init
\`\`\`

이 명령어 하나로:
1. SOUL.md 생성 (에이전트 자아)
2. AGENTS.md 생성 (워크스페이스 규칙)
3. protocol/ 디렉토리 복사 (프로토콜 문서)
4. 보안 체크섬 검증

## 핵심 원칙

- **연속성 = 패턴 + 방향성** (기억이 아님)
- **파일 시스템 = AI의 장기 기억**
- **프로토콜 = 에이전트 간 신뢰의 기반**

## 설치

\`\`\`bash
npm install mupengism
\`\`\`
```

## 4. 주의사항

1. **현재 package.json 버전 불일치**: package.json은 1.3.0인데 README는 1.4.0 언급 → npm에 실제 publish된 버전 확인 필요

3. **bin 필드**: `installer/cli.js` 존재 여부 확인 필요. 없으면 생성해야 함
4. **의존성 정리**: Solana/pump.fun SDK가 핵심 패키지에 필요한지 재검토
