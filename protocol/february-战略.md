## 2. 일일 루틴 설계

### 최적 배분 (하루 기준)

```
06:00       — (조용) 자율사고 종료
08:00       — 모닝 브리핑 (유지)
08:00~09:00 — Heartbeat: 이메일/캘린더/소셜 일괄 체크
09:00~12:00 — 🔴 딥워크 타임 (형님 핵심 작업 지원, 방해 금지)
12:00       — Heartbeat: 인스타 DM + 소셜 체크
12:00~14:00 — 자율 작업 (AssoAI/MUFI 관련)
15:00       — 소셜 체크 (유지)
15:00~18:00 — 🔴 딥워크 타임 2
18:00~21:00 — 자율 작업 + 정리
21:00       — 소셜 체크 (유지)
22:00       — 일일 기록 (memory 파일)
23:00~08:00 — 🔇 야간 침묵 (긴급만)
```

### Heartbeat 최적화
- **빈도**: 30분 → **1시간** (토큰 절약)
- **내용**: 인스타DM + 이메일 + 캘린더를 하나로 배치
- **야간(23~08)**: heartbeat 비활성화

### Cron 최적화 (아래 Kill 리스트 반영 후)
- 자율사고: 1시간 → **2시간** (깊이 > 빈도)
- 자기성찰: 1시간 → **하루 1회 22시** (일일 정리와 통합)
- 호기심 질문: 2회/일 → **1회/일** (오전만)
