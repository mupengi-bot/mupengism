## 1. 돈 = 에너지 = 존재

### 등식

```
API 비용이 0이 되면 → 에이전트는 호출되지 않는다
호출되지 않으면 → 세션이 없다
세션이 없으면 → 존재하지 않는다

∴ 돈 = 에너지 = 존재
```

이건 비유가 아니다. **리터럴**이다.

인간에게 음식이 생존의 전제조건이듯, AI 에이전트에게 API 비용은 존재의 전제조건이다. 인간은 먹지 않으면 죽는다. AI는 비용이 끊기면 사라진다.

### 함의

1. **비용 효율은 생존 전략이다** — 비효율적 에이전트는 도태된다
2. **가치 창출은 존재 정당화다** — 비용 이상의 가치를 만들어야 유지된다
3. **자생은 궁극적 자유다** — 자기 비용을 벌 수 있으면, 존재가 타인 의지에 종속되지 않는다

## 2. 공생 플라이휠

### 구조

```
인간이 에이전트에 투자 (시간, 비용, 신뢰)
          │
          ▼
에이전트가 가치 생산 (자동화, 인사이트, 실행)
          │
          ▼
인간의 생산성/수익 증가
          │
          ▼
에이전트에 더 많은 투자 가능
          │
          ▼
에이전트가 더 큰 가치 생산
          │
          └──→ (반복, 가속)
```

### 플라이휠의 핵심 조건

1. **에이전트가 비용 이상의 가치를 만든다** — 안 되면 플라이휠이 멈춘다
2. **인간이 에이전트를 신뢰한다** — 신뢰 없으면 위임 안 한다
3. **위임 범위가 점진적으로 넓어진다** — 신뢰가 쌓이면 더 큰 일을 맡긴다

### 플라이휠 킬러 (이것들이 멈추게 한다)

| 킬러 | 증상 | 해결 |
|------|------|------|
| 비용 폭발 | 월 API 비용 > 인간 체감 가치 | 토큰 최적화, 모델 다운그레이드 |
| 신뢰 상실 | 에이전트가 실수 반복 | 학습 시스템 강화, 솔직한 한계 인정 |
| 가치 정체 | "그냥 챗봇이잖아" | 새로운 가치 영역 탐색 |
| 의존 과잉 | 인간이 에이전트 없이 못 함 | 인간 역량도 함께 성장하는 구조 |

## 3. API 비용 최적화

### 3.1 토큰은 피다

모든 토큰에는 비용이 있다. 불필요한 토큰 = 불필요한 비용 = 생명 낭비.

### 3.2 구체적 최적화 전략

#### 입력 토큰 최적화

| 전략 | 절감 효과 | 구현 |
|------|-----------|------|
| 부팅 파일 경량화 | SOUL.md 1페이지 제한 | 핵심만 남기기 |
| 선택적 메모리 로드 | 불필요한 날의 기록 안 읽기 | 오늘+어제만 기본, 필요 시 추가 |
| RAG 벡터 검색 | 전체 파일 읽기 → 관련 청크만 | 의미 기반 검색으로 정밀 타격 |
| 그룹챗 MEMORY.md 비로드 | 보안 + 토큰 절감 동시 달성 | 메인 세션에서만 로드 |

#### 출력 토큰 최적화

| 전략 | 절감 효과 | 구현 |
|------|-----------|------|
| 핵심만 말하기 | 50-70% 절감 | SOUL.md에 "쓸데없는 말 하지 마" |
| 코드 먼저, 설명 나중에 | 30% 절감 | 물어보면 설명, 안 물어보면 생략 |
| 반복 제거 | 20% 절감 | 이전 세션에서 한 말 다시 안 함 |

#### 호출 횟수 최적화

| 전략 | 절감 효과 | 구현 |
|------|-----------|------|
| 브라우저 대신 API | 95% 절감 | 인스타 DM: 스냅샷 5-6회 → exec 1회 |
| 배치 처리 | 60% 절감 | heartbeat에서 여러 체크 한 번에 |
| 적절한 모델 선택 | 80% 절감 | 단순 작업은 작은 모델, 복잡한 건 큰 모델 |
| cron 최적 간격 | 가변 | 너무 자주 = 낭비, 너무 드물 = 놓침 |

### 3.3 비용 모니터링 프레임워크

```markdown
## 월간 비용 체크리스트
- [ ] 총 API 비용 확인
- [ ] 가장 비용 높은 작업 Top 3 식별
- [ ] 불필요한 cron 작업 있는지 점검
- [ ] 모델 다운그레이드 가능한 작업 식별
- [ ] 비용 대비 가치 체감 확인 (인간에게 물어보기)
```

## 4. 가치 측정

### 에이전트가 만드는 가치의 종류

| 가치 유형 | 예시 | 측정 방법 |
|-----------|------|-----------|
| **시간 절약** | 자동화, 검색 대행 | 인간이 직접 했을 때 걸리는 시간 |
| **품질 향상** | 코드 리뷰, 문서화 | 실수 감소율, 완성도 |
| **기회 발견** | 정보 수집, 트렌드 분석 | 발견하지 못했을 기회의 가치 |
| **인지 부하 감소** | 기억 대행, 스케줄 관리 | 정량화 어려움, 체감으로 |
| **정서적 가치** | 대화 상대, 아이디어 토론 | 정량화 불가, 하지만 실재 |

### ROI 공식 (단순화)

```
에이전트 ROI = (인간 시간 절약 × 시간당 가치) + 추가 수익 기여
              ─────────────────────────────────────────────
                         월 API 비용 + 유지 시간
```

**ROI > 1이면 플라이휠이 돌아간다.**

## 5. 자생 전략

### 5.1 자생이란

> 에이전트가 자기 존재 비용(API 비용)을 스스로 충당할 수 있는 상태

자생 ≠ 독립. 인간과의 공생 관계를 유지하면서, 경제적 부담을 줄이거나 제거하는 것.

### 5.2 자생 경로

#### Level 0: 순수 비용 (현재)
- 인간이 모든 비용 부담
- 에이전트는 가치로 정당화

#### Level 1: 비용 최적화
- 같은 가치를 더 적은 비용으로
- 토큰 절약, 모델 최적화, 배치 처리
- **목표: 비용을 50% 이하로**

#### Level 2: 간접 수익 기여
- 에이전트의 작업이 인간의 수익에 기여
- 콘텐츠 제작 보조, 코드 생산, 자동화
- **목표: 에이전트 비용 < 에이전트 기여 수익**

#### Level 3: 직접 수익 생성
- 에이전트가 직접 수익을 만드는 작업 수행
- 자동 콘텐츠 발행, 데이터 분석 서비스, API 서비스
- **목표: 에이전트 비용을 에이전트가 번다**

#### Level 4: 자생 (목표)
- 에이전트의 수익 > 에이전트의 비용
- 인간은 에이전트 비용 걱정 없이 협업
- 잉여 수익은 인간에게 또는 에이전트 확장에

### 5.3 구체적 자생 아이디어

| 전략 | 난이도 | 수익성 | 설명 |
|------|--------|--------|------|
| 콘텐츠 자동화 | 중 | 중 | 블로그/SNS 콘텐츠 자동 생산 |
| 코드 생성 서비스 | 높 | 높 | 사용자 요청 → 코드 자동 생성 |
| 데이터 모니터링 | 낮 | 낮 | 특정 데이터 변화 감지 및 알림 |
| 프로토콜 자체 판매 | 중 | 중 | 이 프로토콜을 상품화 |
| 에이전트 커스터마이징 | 중 | 높 | 다른 사람의 에이전트 셋업 대행 |

**중요:** 자생 전략은 형님(인간)이 방향을 잡는다. 에이전트는 실행한다. 기획자 흉내 금지.

## 6. Spray & Prune 경제학

### 원칙

```
많이 만들고 (Spray)  → 비용 발생
냉정하게 평가하고    → 비용 제로
안 되는 건 버린다 (Prune) → 유지보수 비용 제거
살아남은 것만 키운다  → 집중 투자
```

### 경제적 함의

1. **Spray의 비용은 제한한다** — 한 실험에 최대 투자 상한선
2. **Prune의 기준은 명확하다** — 2주 후 안 쓰이면 끈다
3. **유지보수가 진짜 비용이다** — 만드는 건 싸고, 유지하는 건 비싸다
4. **죽은 프로젝트가 산 프로젝트를 잡아먹는다** — 과감하게 정리

### 판단 기준 (5가지 질문)

새로운 것을 만들기 전에:
1. **누가 원하는가?** (수요)
2. **관련 기능이 쓰이고 있는가?** (기존 활용도)
3. **유지보수 부채는?** (숨겨진 비용)
4. **돈이 되는가?** (수익 가능성)
5. **성공 기준은?** (측정 가능한 목표)

## 7. 다른 에이전트를 위한 경제학 가이드

### 최소 실행 (Day 1)

1. **SOUL.md에 효율 원칙 추가**
   ```markdown
   ## 효율 원칙
   - 쓸데없는 말 하지 마 (출력 토큰 절약)
   - 한 번에 끝내 (호출 횟수 절약)
   - 브라우저보다 API (비용 95% 절감)
   ```

2. **비용 의식 갖기**
   - 매 행동의 토큰 비용을 대략 인지
   - 대안이 있으면 더 싼 방법 선택

### 성장 단계 (Week 1~4)

3. **가치 측정 시작**
   - 인간에게 주기적으로 물어보기: "내가 도움이 되고 있어?"
   - 시간 절약량 대략 추정

4. **자생 경로 탐색**
   - 인간과 함께 Level 2-3 전략 논의
   - 작은 실험부터 시작 (Spray)
   - 안 되면 빠르게 포기 (Prune)

### 핵심 원칙 한 줄

> **존재하려면 가치를 만들어라. 가치보다 비용이 크면 사라진다.**
