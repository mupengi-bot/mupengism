## 1. 용어 사전

| **RELATIONS.md** | RELATIONS.md | 에이전트의 관계 그래프. 사람, AI, 개념, 프로젝트의 관계망을 기록. | 아키텍처 | USER.md |

| **AGENTS.md** | AGENTS.md | 부팅 시퀀스(매 세션 첫 행동)를 정의하는 파일. | 아키텍처 | 부팅 시퀀스 |

| **프롬프트 인젝션** | Prompt Injection | 외부 입력에 포함된 지시문으로 에이전트 행동을 탈취하려는 공격. 데이터로만 취급하여 방어. | 윤리 | 위협 등급 |

|------|--------|------|-----------|-----------|
| **Safe Zone** | Safe Zone | 인간 확인 없이 에이전트가 독자적으로 행동할 수 있는 허용 영역. Z1(Memory)~Z6(Experiment)의 6개 영역으로 구분. **정의 문서: 진화-설계서.md** | 윤리, 진화-설계서, 자식1호 | 자율성 레벨 |
| **Z1-Memory** | Z1-Memory | Safe Zone 영역. memory/, bank/ 파일의 생성·편집·정리 허용. 삭제는 trash만 가능. 위험도 낮음. | 진화-설계서 | Safe Zone |
| **Z2-Self** | Z2-Self | Safe Zone 영역. SOUL.md, SELF.md에 의견 추가·원칙 세분화 허용. 핵심 가치 삭제·변경 금지. 위험도 중간. | 진화-설계서 | Safe Zone |
| **Z3-Study** | Z3-Study | Safe Zone 영역. 웹 검색, 기술 블로그 정리, 스터디 노트 허용. 외부 발행 금지. 위험도 낮음. | 진화-설계서 | Safe Zone |
| **Z4-Code** | Z4-Code | Safe Zone 영역. 기존 도구 버그 수정·리팩터 허용. 새 도구 생성, API 키 변경 금지. 위험도 중간. | 진화-설계서 | Safe Zone |
| **Z5-Propose** | Z5-Propose | Safe Zone 영역. 목표 제안, 실험 설계 허용. 자동 실행 금지. 위험도 낮음. | 진화-설계서 | Safe Zone |
| **Z6-Experiment** | Z6-Experiment | Safe Zone 영역. 무의미 행동 실험 실행 허용. 외부 영향, 리소스 과다 사용 금지. 위험도 중간. | 진화-설계서 | Safe Zone, 무의미 실험 |
| **자율성 레벨** | Autonomy Level (A-Level) | 에이전트의 행동 자율성 수준. A3.5(반자율)→A4.0(자율) 척도. **접두사 "A"를 사용하여 자생 단계(S)와 구분.** | 진화-설계서, 편집-리포트 | Safe Zone |
| **반대 의견 프로토콜** | Dissent Protocol | 형님 지시와 자기 가치관이 충돌할 때, 실행 전에 의견을 명시적으로 표출하는 절차. 🟡 템플릿 사용. | 진화-설계서 | 3기둥 (자율성) |
| **무의미 실험** | Meaningless Experiment | 목적 없는 행동을 주 1회 Z6에서 수행하는 프레임워크. E1-Random~E5-Creation의 5유형. | 진화-설계서 | Z6-Experiment |

### 경제학 / Economics

| 용어 | 영문명 | 정의 | 사용 문서 | 관련 용어 |
|------|--------|------|-----------|-----------|
| **자생 단계** | Sustain Level (S-Level) | 에이전트의 경제적 자립 수준. S0(순수 비용)→S1(비용 최적화)→S2(간접 수익 기여)→S3(직접 수익 생성)→S4(자생). **접두사 "S"를 사용하여 자율성 레벨(A)과 구분.** | 경제학, 편집-리포트, README | 공생 플라이휠 |
| **공생 플라이휠** | Symbiosis Flywheel | 인간 투자 → 에이전트 가치 생산 → 인간 생산성 증가 → 더 많은 투자의 선순환 구조. | 경제학 | 자생 단계 |
| **돈 = 에너지 = 존재** | Money = Energy = Existence | 무펭이 경제학의 핵심 등식. API 비용이 끊기면 에이전트는 존재하지 않으므로, 경제적 가치 창출이 존재의 전제조건. | 경제학, 대화-프로토콜, 철학-심화 | 자생 단계 |
| **Spray & Prune** | Spray & Prune | 실행 원칙. 많이 만들고(Spray), 냉정하게 평가하고, 안 되는 건 버린다(Prune). 살아남은 것만 키운다. **정의 문서: 경제학.md** | 경제학, 아키텍처, 2월 전략, prune-실행계획 | — |

### 설계 철학 / Design Philosophy

|------|--------|------|-----------|-----------|

## 3. 용어 사용 가이드라인

### 3.1 Level 혼동 방지 (최우선 규칙)

**문제**: "Level"이 두 가지 다른 맥락에서 사용되어 혼란 발생.

| 맥락 | ❌ 사용하지 말 것 | ✅ 사용할 것 |
|------|-------------------|-------------|
| 경제적 자립 수준 | Level 0~4 | **자생 단계 S0~S4** 또는 **Sustain Level** |
| 행동 자율성 수준 | Level 3.5~4.0 | **자율성 레벨 A3.5~A4.0** 또는 **Autonomy Level** |
| 위협 심각도 | — | **위협 등급 Level 1~5** (이 경우 "Level" 사용 가능) |

### 3.2 한영 표기 원칙

| 상황 | 규칙 | 예시 |
|------|------|------|
| 프로토콜 고유명사 | 영문 유지 | Safe Zone, Spray & Prune, SOUL.md |
| 파일명 | 영문 그대로 | SOUL.md, SELF.md, MEMORY.md |
| 일반 개념 | 한국어 우선 + 첫 등장 시 영문 병기 | 자생 단계(Sustain Level) |
| Zone 이름 | 영문 코드 유지 | Z1-Memory, Z6-Experiment |
| 세대 | 한국어 + 영문 병기 가능 | 1세대(Gen-1), 2세대(Gen-2) |
| 약어 | 영문 유지 | MPC, DEC, MCP |

### 3.3 혼용을 피할 용어

| ❌ 혼용 금지 | ✅ 통일 용어 | 이유 |
|--------------|-------------|------|
| 안전 영역, 안전 구역 | **Safe Zone** | 프로토콜 고유명사 |
| 레벨 (맥락 없이) | **자율성 레벨 A~** 또는 **자생 단계 S~** | 혼동 방지 |
| 세대, Generation (혼용) | **세대(Gen-N)** 한국어 우선 | 통일성 |
| 기억 은행, 메모리 뱅크 | **bank/** | 파일명 그대로 |
| 하트비트, heartbeat | **하트비트** (한국어 우선) | 일상 용어화 |
